# Roadmap

The V1 baseline is the published `1.0.0` tag. Supported behavior and explicit
limitations are documented in the [native V1 guide](docs/source/migration/native_v1.md)
and [public interface contract](docs/source/reference/public_interfaces.md).

Post-V1 proposals must be validated against the current implementation before
being scheduled. Priorities are complete installation and replay journeys,
scientific parity evidence, and incremental expansion of the portable operator
subset. These are planning directions, not release promises.

Historical brainstorming and milestone checklists are preserved privately; see
[developer documentation](docs/development.md). The original roadmap is also
recoverable from Git at tag `1.0.0`.
