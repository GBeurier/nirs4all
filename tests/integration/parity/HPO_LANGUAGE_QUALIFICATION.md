# Host HPO qualification across bindings

The native HPO contract and an operator's implementation are separate claims. DAG-ML owns trial scheduling, fold identity, native scoring, pruning, selection, and checkpoint validation. Each host owns model fitting and predictions. A passing JSONL handshake or a callback that returns fabricated predictions qualifies the protocol, not a real host model.

| Surface | Current HPO evidence | Operator exercised | Remaining qualification |
| --- | --- | --- | --- |
| nirs4all Python / PyO3 | `test_dagml_cli_runner.py::test_adaptive_finetune_params_execute_with_native_inner_fold_scores[in_process]` covers a real RandomForest search and native grouped inner-fold scores. Other public `finetune_params` tests and `dag-ml-py/tests/test_host_hpo_resume.py` cover model-local searches and checkpoint transitions. | Real Python RandomForest, Ridge residual learner, and PyTorch model-local searches; PyO3 scheduler tests also use synthetic callbacks. | Compare actual trial scores and winner against the CLI mechanism on a fixed dataset. |
| nirs4all Python / DAG CLI process | The same RandomForest test forces `N4A_DAGML_INPROCESS=0` and checks grouped native inner-fold scores from the captured fitted model. | Real Python RandomForest inside the process adapter. | Detached refit/archive replay and interrupted resume for that same operator/search. |
| Standalone CLI + Python/R/Octave optimizer JSONL | `dag-ml-cli::host_hpo_cli_runs_parallel_pruning_and_resumes_native_checkpoint`, `r_hpo_ridge.rs`, and `octave_hpo_ridge.rs` verify native fold scores, parallel trials, pruning, resume, selected-parameter REFIT and fresh-process replay. | Real R Ridge and Octave Ridge operators; RDS and MAT sidecars are integrity-checked. | Other operators need their own codec/executor evidence; proprietary MATLAB still needs a runtime oracle. |
| R and MATLAB/Octave wrappers | Wrapper tests check forwarding; real R and Octave Ridge HPO tests use the CLI and local model implementations, then full-train REFIT and fresh-process artifact replay. | R Ridge and Octave Ridge, including RDS/MAT artifacts. | Proprietary MATLAB has no runtime qualification; do not infer it from Octave. |
| JS/WASM Node workers | `scripts/smoke_wasm_hpo.cjs` verifies fold-local scalar Ridge, native OOF scores, concurrent dispatch, pruning, resume, selected-parameter REFIT and artifact replay. | Host-local scalar Ridge on declared train IDs. | Other JS estimators require separate operator oracles. |
| JS/WASM Chrome Web Workers | `scripts/smoke_wasm_browser_hpo.mjs` verifies real module workers, native fold scores, pruning/resume, selected Ridge REFIT and replay. | Browser-local scalar Ridge on declared train IDs. | Other browser estimators require separate operator oracles. |
| C ABI | Native callback and recovery tests cover the HPO protocol. | Fixture callbacks, not an independent language's estimator. | At least one C/C++ host operator smoke with fresh-process resume. |
| Native Methods PLS | Separate `methods_hpo_operation` route produces portable N4MOPT/N4MM evidence. | Real Methods PLS. | Keep this as a portable operator qualification; it does not establish host-local estimator parity. |

To extend the shared real-operator matrix, use a small seeded regression dataset, a published two-fold `FoldSet`, and a closed two- or three-value regularization grid. Require each new binding/operator pair to report sample IDs, per-fold predictions, native fold scores, trial states and order, winner, full-train refit predictions, and a replayable artifact. Allow documented floating-point tolerances for different solvers. Run one uninterrupted search and one interrupted/resumed search with parallel trials and a pruning case. A test must fail rather than silently substitute a synthetic controller when its language runtime or model implementation is required in CI.

The qualified matrix now has real operator oracles for Python, R, Octave, Node and Chrome, with REFIT and replay on the R/Octave/JS examples above. The portable HPO scheduler remains operator-agnostic; each additional estimator needs its own fitted-state codec and replay test. Octave was validated locally, but this document does not assert that every CI workflow provisions Octave. Proprietary MATLAB and a standalone C/C++ host estimator remain unqualified. `feature_gaps.json` retains `inventory_complete=false` until the final controller inventory review is complete; the small-sample deep-MetaModel refusal is documented as a legacy label-leakage divergence.
